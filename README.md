# 我們的一週

# 📥 [👉 點這裡下載 APP 👈](https://github.com/doul0663-svg/ourweek/releases/latest/download/ourweek.apk)

情侶共享的週計畫 APP：填寫這週、下週有空沒空和要做的事，看見彼此的空白時間。

## 安裝步驟

1. 用 Android 手機點上面的 **「點這裡下載 APP」**
2. 下載完點開安裝（第一次要允許「安裝未知來源的應用程式」）
3. 打開 APP，填名字，輸入對方給你的邀請碼

已經裝過的話，打開 APP 會自動提示更新，不用回來這裡。

> 這個倉庫只放安裝檔，不放程式碼。
